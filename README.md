# Chew Zhi Xin — Portfolio

A clean, responsive personal portfolio for GitHub Pages.

## Preview locally

From this repository, start a local static server:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Customize

- Update the name, introduction, project names, and social links in `index.html`.
- Replace the portrait placeholder and project mockups with real images or case studies.
- Update the colors and typography in `styles.css`.
- Replace `hello@example.com` with your real email address.

This site is ready to publish from the repository root with GitHub Pages.
